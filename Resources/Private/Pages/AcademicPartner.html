The page template of the partner page type. It renders the section "Main" of the page layout of the site, "Default" unless the site setting "plugin.tx_academicpartners.page.layout" names another one. A site without a layout "Default" gets the fallback layout of this extension, which renders the section alone. A layout the setting names has to exist. Each part is a partial below "Partner/Page/", so a project replaces one of them rather than this file. The page record: the record of the page information object "page" a PAGEVIEW page object assigns, or "data" of a FLUIDTEMPLATE page object. "page" first, because PAGEVIEW reserves that name, while a PAGEVIEW site package may assign a "data" of its own.
