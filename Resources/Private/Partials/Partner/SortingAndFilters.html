A change of a select submits the form through its inline `onchange` handler. The extension allows exactly that handler text in the Content Security Policy of TYPO3, see `Configuration/ContentSecurityPolicies.php`, so an override of a partial that changes the text needs the hash of its own text in the `csp.yaml` of the site. The button submits the form for a visitor without JavaScript.
The active filters, the reset link and the result count are switched on per site by `settings.filter.showActiveFilters`, `showReset` and `showResultCount`. The first two belong to the filter, so a list whose filter is hidden shows neither.
